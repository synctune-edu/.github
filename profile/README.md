# Synctune Edu

Synctune Edu is a branch of [Synctune](https://github.com/synctune-io), focused on software and practical resources for learning, mentorship, and engineering careers. We help people build skills, prepare for interviews, and navigate their next role.

## Projects

| Repository | Focus |
| --- | --- |
| [go-get-a-job](https://github.com/synctune-edu/go-get-a-job) | A paid job application tracking, resume review, and application preparation SaaS. |
| [engineering-interviews](https://github.com/synctune-edu/engineering-interviews) | Engineering interview preparation. Free and Open Source. |
| [mentorships](https://github.com/synctune-edu/mentorships) | Mentorship and career-development resources, not public. |
| [coding-challenges](https://github.com/synctune-edu/coding-challenges) | Interview coding exercises and programming utilities, also not public. |

Repository links use their planned organization locations. Some may be private or pending transfer.
